# Data buku  Dictionary
## Fitur Fitur dalam code berikut yaitu
  1. Tampilkan data buku
  2. Tambah key Penerbit ke dictionary
  3. Ubah key penulis
  4. Hapus key Penerbit dari dictionary
  5. Program selesai

## Algoritma yang digunakan
1. Dictionary menyimpan data key dan value
2. While loop menjalankan menu secara berulang
3. Tambah key dBuku["penerbit"] 
4. Ubah key dBuku["penulis"]
5. Hapus key del dBuku["penerbit"]
